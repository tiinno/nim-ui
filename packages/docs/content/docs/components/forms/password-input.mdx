title: PasswordInput

import { PasswordInput } from '@/components/nim';

PasswordInput keeps Input styling but adds an accessible show/hide toggle.

## Import

```tsx
import { PasswordInput } from '@nim-ui/components';
```

## Basic Usage

<ComponentPreview title="Approval Password">
  <div className="w-72">
    <PasswordInput name="approvalPassword" autoComplete="current-password" placeholder="Password" />
  </div>

  <PreviewCode>
```tsx
<PasswordInput
  name="approvalPassword"
  autoComplete="current-password"
  placeholder="Password"
/>
```
  </PreviewCode>
</ComponentPreview>

## Props

`variant` and `size` come from Input — PasswordInput reuses its styling, so a validation state or a size set here behaves exactly as it does on an Input.
